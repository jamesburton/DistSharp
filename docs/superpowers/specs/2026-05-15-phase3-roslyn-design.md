# DistSharp — Phase 3: Roslyn Analyzer

**Date:** 2026-05-15
**Scope:** `DistSharp.Roslyn` project — implements `ISolutionAnalyzer` and provides two pipeline steps (`RoslynSymbolExtractorStep`, `StratifiedSamplerStep`).

---

## 1. Goals

1. **`RoslynSolutionAnalyzer`** — concrete `ISolutionAnalyzer` that loads a `.sln`/`.csproj`/directory and yields `ExtractedSymbol` records.
2. **`RoslynSymbolExtractorStep`** — `IStep` that runs the analyzer for a configured solution and emits one `Row` per symbol.
3. **`StratifiedSamplerStep`** — `IStep` that samples a configured number of rows using a chosen strategy (uniform or complexity-weighted).

---

## 2. Components

### `RoslynSolutionAnalyzer : ISolutionAnalyzer`

**Constructor:** takes `ILogger<RoslynSolutionAnalyzer>` for diagnostics.

**Loading approach:**
- `MSBuildLocator.RegisterDefaults()` is called once globally on first use (idempotent via `MSBuildLocator.IsRegistered`)
- `MSBuildWorkspace.Create()` to open `.sln` or `.csproj`
- For a directory: scan recursively for `*.sln`, fall back to `*.csproj` if no `.sln` found
- Workspace failures are logged as warnings; analysis continues with what loaded

**Symbol extraction:**
- For each `Project` in the workspace, get its `Compilation`
- For each `SyntaxTree` in the compilation, walk for declarations
- Use a `CSharpSyntaxWalker` subclass `SymbolExtractor` that produces `ExtractedSymbol` for:
  - `MethodDeclarationSyntax`
  - `PropertyDeclarationSyntax` (skip individual accessors)
  - `ConstructorDeclarationSyntax`
  - `ClassDeclarationSyntax`, `StructDeclarationSyntax`, `RecordDeclarationSyntax`, `InterfaceDeclarationSyntax`, `EnumDeclarationSyntax` (these get `Kind = class/struct/record/interface/enum`; for class/struct/record/interface their `BodyText` is the full declaration text)
- Get symbol info via `SemanticModel.GetDeclaredSymbol(node)` to resolve fully qualified names

**Filtering (applied during walk):**
- Skip if `IncludeTests = false` and the project is identified as a test project:
  - Project name endsWith `.Tests`, `.Test`, `.UnitTests`, `.IntegrationTests`
  - Or any compilation reference targets `xunit.core`, `Microsoft.NET.Test.Sdk`, `MSTest.TestFramework`, `nunit.framework`
- Skip if `IncludeGenerated = false` and the file path matches `*.g.cs`, `*.designer.cs`, or the syntax tree's first token has a `<auto-generated>` trivia
- Skip if `MinComplexity > 0` and symbol's computed complexity < threshold (only applies to methods; types and properties are always included regardless of complexity)
- Skip if `Namespace.StartsWith(prefix)` for any prefix in `ExcludeNamespaces`
- Skip symbols with `Accessibility.Private` or `Accessibility.Protected` (only Public + Internal kept)

**Cyclomatic complexity** (`CyclomaticComplexityCalculator`):
- Visit method body via syntax walker; count: `if`, `else if`, `case` (in switch), `while`, `for`, `foreach`, `do`, `catch`, `&&`, `||`, `?:` (conditional), `??`, switch expression arms
- Base = 1; each branching adds 1
- Public method `Compute(SyntaxNode body) → int`

**Streaming:**
- `AnalyzeAsync` is `async IAsyncEnumerable<ExtractedSymbol>` with `[EnumeratorCancellation]`
- Yield symbols as each tree is walked (no fully buffered list)

**Body text cleaning:**
- For methods/constructors: `node.Body?.ToFullString() ?? node.ExpressionBody?.ToFullString() ?? ""`
- For properties: full property declaration text including get/set
- For types: the entire declaration text

**Error handling:**
- Workspace open failures → log warning, return empty stream
- Per-file compilation errors → log debug, skip that file, continue
- Cancellation → respect `CancellationToken` between trees

### `RoslynSymbolExtractorStep : IStep`

**Configuration** (from `StepConfig.Config` dictionary):
- `solution_path` (string, required) — path to .sln/.csproj/directory
- `include_tests` (bool, default false)
- `include_generated` (bool, default false)
- `min_complexity` (int, default 3)
- `exclude_namespaces` (list of strings, default empty)
- `symbol_kinds` (list of strings, default `["method", "property", "class", "interface"]`) — filters by Kind
- `max_body_lines` (int, default 0 = unlimited) — truncate BodyText to first N lines if set

**Constructor:** `(string name, ISolutionAnalyzer analyzer, RoslynSymbolExtractorOptions options)` — options derived from StepConfig.

**Execution:**
- Ignores input channel (it's a source step)
- Builds `SolutionAnalysisOptions` from the configured options
- Calls `analyzer.AnalyzeAsync(solutionPath, options, ct)`
- For each extracted symbol matching `SymbolKinds`:
  - Apply `max_body_lines` truncation if set
  - Create a `Row` with field `symbol` = the `ExtractedSymbol`, plus flattened convenience fields:
    - `kind`, `name` (= FullyQualifiedName), `namespace`, `file_path`, `complexity`
  - Write to output channel

### `StratifiedSamplerStep : IStep`

**Configuration** (from `StepConfig.Config`):
- `max_rows` (int, required)
- `strategy` (string, default `complexity_weighted`) — `uniform` or `complexity_weighted`
- `seed` (int?, optional) — for reproducible sampling

**Execution:**
- Buffer all input rows into a `List<Row>`
- If `Count <= MaxRows`: emit all rows (no sampling needed)
- Else: apply strategy
  - `uniform`: shuffle with seeded `Random`, take first `MaxRows`
  - `complexity_weighted`: weight each row by `max(1, row.Get<int>("complexity"))`, use weighted reservoir sampling (algorithm A-Res from Efraimidis-Spirakis)
- Emit sampled rows to output in original order (sort by index)

**Memory cost:** `O(n)` for buffering. Acceptable for current scale (~100k rows × small Row objects).

## 4. Tests

`tests/DistSharp.Roslyn.Tests/`:

1. **`CyclomaticComplexityCalculatorTests`** — given various method bodies, verify expected complexity
   - Empty method → 1
   - Method with single if → 2
   - Method with if/else → 2 (else doesn't add)
   - Method with nested if + while → 3
   - Method with `&&` in condition → adds 1
   - Method with switch (5 cases) → 6 (1 base + 5 cases)

2. **`RoslynSolutionAnalyzerTests`** — uses an embedded sample .csproj fixture
   - Create a tiny test project as a string-to-disk fixture in `Tests/Fixtures/SampleProject/`
   - Analyze it, verify symbols extracted match expected
   - Test test-project filtering (project named `.Tests` is skipped when `IncludeTests = false`)
   - Test namespace exclusion
   - Test complexity filtering

3. **`StratifiedSamplerStepTests`** — feed 1000 fake rows, sample 100
   - Uniform: verify count = 100
   - Complexity-weighted: verify high-complexity rows are over-represented
   - Pass-through when count ≤ max_rows

4. **`RoslynSymbolExtractorStepTests`** — basic integration: configure with the fixture path, run, verify rows are emitted
